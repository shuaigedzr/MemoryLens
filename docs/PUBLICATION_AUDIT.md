# Publication scope and audit

Prepared 18 November 2026 under explicit authorisation to publish only the independent MemoryLens project.

## Scope inspected

The original MemoryLens working tree and its single reachable local commit were inventoried. All reachable Git commit/blob contents, original DOCX XML and PDF text/metadata were scanned for known credential formats, private-key headers, credential assignments, academic identifiers, personal paths, private-project references and assessment details. Git integrity inspection found no unreachable objects. No other repository was read or modified.

No known-format credential/private-key matches were found. Identifying academic material and private source inventories were found, so the original history is not pushed. The public repository is a new reviewed snapshot with no parent from that history. Private originals are preserved locally.

## Public contents

Application HTML/CSS/JavaScript, package metadata, engine tests, validation/replay helpers, authored architecture, real screenshots of fictional fixtures, fictional browser exports and reviewed documentation. The report generator and identified Word/PDF/Markdown report are omitted; the submission report is supplied privately. No lecture PDFs, Canvas screenshots, historical ZIPs, API credentials, private notes or other-project source files are included.

Images were inventoried, visually reviewed and checked with OCR. Public text, filenames, image metadata and new Git history are rechecked before push. Checks reduce disclosure risk; the report records the methods and observed findings rather than claiming an absolute proof that no conceivable secret exists.

Version 1.0.1-local identifies the application package. The public Git commit is the assessed source version. No Git tag or GitHub Release is claimed. Anonymous repository/README access and an unauthenticated clone are checked after push; their final results are supplied with the report.
